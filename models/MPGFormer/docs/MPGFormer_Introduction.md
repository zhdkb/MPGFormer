# MPGFormer 论文 Introduction 中文草稿

现代云平台已经成为支撑在线服务、微服务系统、数据库、推荐系统、流式计算、批处理任务以及 AI 训练和推理任务的关键基础设施。与传统单机或静态集群环境不同，云平台中的计算资源被大量异构应用共同使用，工作负载会持续受到用户访问行为、业务调用链、调度策略、后台维护任务、资源竞争以及突发系统事件的共同影响。对于云服务提供者而言，准确预测未来一段时间内的资源需求，是自动扩缩容、资源预留、容量规划、能耗优化和服务质量保障的重要前提。如果平台能够提前感知 CPU、内存、请求量或服务负载的变化，就可以在负载上升前完成资源准备，在负载下降后及时释放冗余资源，从而同时降低资源浪费和性能风险。

然而，云工作负载预测并不是一个简单的时间序列外推问题。真实云环境中的 workload 往往不是由某个固定、稳定且长期不变的时间规律生成的。即使观察对象是同一个长期运行的服务实例，它在一天或数天的正常运行过程中也可能经历多种完全不同的运行状态。某些时间段中，负载具有明显的日周期或小时级周期，历史节律能够较好解释未来变化；某些时间段中，负载会因为突发访问、调度事件、批量任务启动或后台维护而快速升高；某些时间段中，多个实例或服务会因为共享上游流量、相同业务流程、共同调度策略或资源竞争而同步波动；还有一些时间段中，负载的均值、方差或局部形态会逐渐偏离历史典型模式，进入一种漂移或非典型状态。

这些变化并不一定意味着出现了新机器、新应用或冷启动场景。更常见的情况是：服务仍然是同一个服务，机器仍然是已有机器，应用也已经运行了很长时间，但它在不同时间窗口中呈现出的预测状态却发生了变化。也就是说，云工作负载的困难不只来自“要预测一个未知实体”，还来自“同一个已知实体在运行过程中不断改变其可预测方式”。这使得云工作负载预测面临一个更隐蔽但更关键的问题：最可靠的预测证据并不是固定的。

在稳定的周期窗口内，模型应更多地依赖于时间记忆和多尺度周期模式，因为此时历史节律对未来变化具有较强解释力。而在突发性高负载窗口内，局部短期变化比长期依赖关系更具参考价值，因为突发峰值往往由最近几个时间点的快速变化触发。在协同波动窗口中，近期行为相似的工作负载可以提供有用的跨序列证据，因为多个实例可能同时受到相同上游流量、调度事件或系统操作的影响。在漂移或非典型窗口中，模型应谨慎地避免直接从历史模式进行外推，而应评估其学习到的工作负载原型的不确定性。因此，关键问题不仅在于如何设计更强大的序列编码器，还在于如何在当前工作负载状态下确定哪种证据来源应主导预测。

这一观察表明，云工作负载预测本质上是一个状态依赖的证据选择问题。模型在进行预测之前，需要理解当前窗口所处的运行状态，并判断哪一种预测证据在该状态下更加可信。对于稳定窗口，周期性和历史节律可能是最可靠的；对于突发窗口，短期局部变化可能比长程依赖更重要；对于协同波动窗口，其他相似实例的近期行为可能比目标实例较久远的历史更有参考价值；对于漂移窗口，模型需要意识到当前模式可能偏离了已有经验，并降低对固定历史模式的盲目信任。

为了更直观地理解这一问题，可以考虑一条来自长期在线云服务的 workload trace。上午时段，该服务的资源需求可能随着用户活跃度逐渐上升，并且与过去几天的日周期相似。几个小时后，它可能因为一次短时间流量冲击或批量调度事件出现尖峰。随后，该服务又可能与其他几个实例一起上升或下降，因为它们共同受到某个上游请求链路或系统操作的影响。到了晚间，该服务可能进入新的局部尺度，使当前窗口的均值、方差和形态都与之前的典型模式不同。对于云平台来说，这些片段都来自同一个已知服务；但对于预测模型来说，它们需要的预测逻辑并不相同。如果模型始终假设所有窗口都应依赖同一种证据，就会掩盖云工作负载中最真实、也最容易造成预测误差的状态切换现象。

基于上述动机，本文提出 MPGFormer，即 Drift-Aware Multi-scale Prototype-Graph Transformer。MPGFormer 的核心思想不是把云工作负载预测仅仅看作更长历史序列的编码问题，而是将其重新表述为漂移感知的动态证据选择问题。模型需要同时感知时间历史、局部突发变化、典型负载形态以及跨序列协同关系，并根据当前窗口的运行状态决定不同证据的可信程度。换句话说，MPGFormer 关注的不是某一种预测证据是否永远有效，而是不同证据在不同运行状态下何时应该被信任。

具体而言，MPGFormer 从多个互补视角刻画 workload 窗口。时间视角用于保留目标序列自身的历史演化信息，帮助模型捕捉稳定周期和长短期依赖。局部视角用于刻画短时间范围内的快速变化，使模型能够响应突发峰值和局部异常。原型视角用于描述云工作负载中反复出现的典型形态，例如周期性上升、平台型高负载、低谷恢复、尖峰过渡以及不规则漂移；同时，原型匹配的不确定性能够提示当前窗口是否偏离了模型已有经验。跨序列视角用于捕捉同一云平台中不同实例之间的近期协同关系，使模型能够利用行为相似 workload 所提供的外部证据。

MPGFormer 进一步引入漂移感知的证据融合思想，使这些证据不是被简单拼接或平均，而是根据当前窗口状态动态调整其影响力。当窗口表现出稳定周期时，模型可以更多依赖时间记忆和典型原型；当窗口表现出突发高负载时，局部短期变化应获得更高权重；当窗口出现明显协同波动时，跨序列关系应成为重要参考；当窗口处于漂移或非典型状态时，模型需要降低对固定模式的过度依赖，并采用更加谨慎的证据组合。通过这种方式，MPGFormer 试图让预测过程与云工作负载真实的运行状态变化保持一致。

本文的主要贡献可以概括如下。

1. 本文提出一种面向云工作负载预测的状态依赖证据选择视角，指出同一条 workload 序列在正常运行过程中会不断切换预测状态，从而导致最可靠的预测证据随时间变化。

2. 本文提出 MPGFormer，一个漂移感知的多尺度原型图 Transformer，将时间历史、局部短期变化、典型负载原型和跨序列关系纳入统一的预测框架。

3. 本文通过多尺度时频原型刻画云工作负载中反复出现的典型形态，并利用原型匹配不确定性帮助识别漂移或非典型窗口。

4. 本文建模动态跨序列关系，使模型能够在协同波动窗口中利用近期行为相似 workload 所提供的外部证据，而不依赖固定不变的关系假设。

5. 本文设计漂移感知的证据融合机制，使模型能够根据当前窗口状态自适应调整不同预测证据的影响力，从而提升在稳定、突发、协同波动和漂移场景下的预测鲁棒性。

总之，MPGFormer 将云工作负载预测从“固定证据源的时间外推”重新定义为“漂移感知的动态证据选择”问题。它的目标不仅是预测未来数值，更是判断在当前运行状态下哪些历史、形态和跨序列信息最值得信任。这一视角更贴近云平台中 workload 状态持续变化、实例关系动态演化、历史模式可靠性不断改变的真实运行过程。
